# Security Policy

## Supported Versions

Security fixes are generally considered for the latest version of Calculator App. Please update to the latest available release before reporting an issue whenever possible.

## Reporting a Vulnerability

If you believe you have found a security vulnerability, please report it privately to the project maintainer.

- **Preferred:** Use GitHub's private vulnerability reporting feature for this repository, if it is enabled.
- **Alternative:** Contact the maintainer privately through GitHub.

Please do not disclose suspected vulnerabilities publicly in Issues, Discussions, or Pull Requests until the maintainer has had a reasonable opportunity to review the report.

When reporting a vulnerability, include:

- A clear description of the potential security issue.
- The affected platform or component (shared web interface, desktop/Electron wrapper, or Android/Flutter WebView wrapper).
- Steps to reproduce the issue, including any relevant configuration.
- The potential impact and, if known, a suggested mitigation.
- Relevant logs or screenshots, with secrets and personal information removed.

## Scope

Security reports may concern the shared calculator interface or its desktop and mobile wrappers. Examples include unsafe handling of untrusted input, unintended navigation, exposure of sensitive data, or insecure platform configuration.

Please distinguish vulnerabilities in Calculator App from issues in the operating system, browser engine, Electron, Flutter, or other third-party components. Reports involving dependencies are welcome when they demonstrate a security impact on this project.

## Response

The maintainer will review reports as reasonably possible and may request additional information. There is no guaranteed response or remediation timeline. Please allow time for investigation and coordinated disclosure.

Thank you for helping keep Calculator App and its users safe.
